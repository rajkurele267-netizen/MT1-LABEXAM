# MT1-LABEXAM – Online Food Ordering

Run (inside `FoodOrdering/`, after `npm install`):
- `node httpServer.js` → http://localhost:3000 (/, /foods, /about, /menu, POST /add-food)
- `node expressApp.js` → http://localhost:4000 (GET/POST /foods, GET/PUT/DELETE /foods/:id)

Put screenshots (HTTP server, /menu, Postman GET/POST/PUT/DELETE) in `FoodOrdering/screenshots/`.
